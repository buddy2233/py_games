# Pygame Arcade Collection

Collection of classic games built with Python and Pygame.

## Games included
- **Snake** - Eat apples, don't hit walls or yourself
- **Block Breaker** - Breakout clone with paddle + ball
- **Maze** - Navigate through a random maze
- **Pong** - 2 player paddle game
